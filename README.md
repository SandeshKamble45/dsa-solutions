# DSA Interview Prep

A daily-maintained collection of Data Structures & Algorithms problems, solved with clear explanations, complexity analysis, and multiple approaches where relevant. Built while preparing for SDE interviews — sharing in case it helps someone else on the same grind.

## Why this repo exists
Most solution dumps online are just code with no reasoning. Every problem here includes:
- Problem summary
- Brute-force vs optimal approach
- Time & space complexity
- Key insight / pattern used
